Где искать

Это запросы для поиска групп. Уберите лишние или добавьте свои.

Claude — разбор поста

Не обязательно. Без ключа всё бесплатно: запросы подбираются по словам из поста. С ключом Claude понимает суть услуги, лучше подбирает, где искать аудиторию, и оценивает найденные группы — это стоит доли цента за пост.

Платно: примерно 3–8 центов за поиск на одной площадке. Выключено — поиск бесплатный: вы ищете сами по готовым ссылкам, а приложение ведёт учёт.

ВКонтакте

Поиск групп ВК бесплатный, но ВК пускает только после входа. Войти нужно один раз: откроется официальная страница VK ID, и после входа вы вернётесь сюда.

Для входа через ВК нужна новая версия приложения. и установите поверх текущей — все данные сохранятся.

Telegram

Войдите своим аккаунтом Telegram — приложение само найдёт открытые чаты и каналы по вашим запросам через глобальный поиск Telegram. Бесплатно. Приложение только ищет: ничего не пишет и не публикует от вашего имени.

Telegram через TGStat API — платно

Бесплатно Telegram-каналы и чаты ищутся по ссылкам на сайт TGStat. Если у вас есть платный тариф TGStat API, приложение будет само собирать список с числом подписчиков. В чатах участники обычно могут писать сами, в каналах публикует только админ.

Facebook

Facebook закрыл поиск групп для приложений, поэтому в бесплатном режиме вы получаете готовые ссылки на поиск по каждому запросу.
