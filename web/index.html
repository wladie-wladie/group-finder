Где искать

Это запросы для поиска групп. Уберите лишние или добавьте свои.

Claude — разбор поста

Без ключа приложение подбирает запросы по словам из поста. С ключом Claude понимает суть услуги, придумывает, где искать аудиторию, оценивает группы и читает их правила.

ВКонтакте

Поиск групп ВК бесплатный, но ВК пускает только после входа. Вход нужен один раз.

  1. Создайте своё приложение на (тип «Standalone» или «Web»), скопируйте его ID.
  2. Вставьте ID ниже и нажмите «Войти через ВК».
  3. После входа откроется пустая страница. Скопируйте её адрес целиком из адресной строки и вставьте в поле ниже.

Telegram — платно

У Telegram нет открытого поиска каналов и чатов. Поиск идёт через каталог TGStat по вашему платному тарифу API. В чатах участники обычно могут писать сами, в каналах публикует только админ, так что там размещение через него.

Facebook

Facebook закрыл поиск групп для приложений. Вместо списка групп вы получите готовые ссылки на поиск по каждому запросу.
