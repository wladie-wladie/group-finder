# Где разместить

Android-приложение, которое подбирает тематические группы под ваш пост об услуге.
Публикуете вы сами: приложение копирует текст поста и открывает группу, а вы вставляете его по правилам этой группы.

- **Разбор поста.** Claude (по вашему ключу API) определяет суть услуги и аудиторию и предлагает запросы для поиска. Без ключа работает простой режим по словам из поста.
- **ВКонтакте** — бесплатный поиск через официальный API после входа. Закрытые группы скрываются, видно, можно ли писать на стену или только предложить новость.
- **Telegram** — платная опция через каталог TGStat по вашему токену API. Чаты и каналы отмечаются отдельно.
- **Facebook** закрыл поиск групп для приложений, поэтому вместо групп вы получаете готовые ссылки на поиск.
- Claude оценивает, насколько группа подходит, и читает её правила: реклама разрешена, платно или запрещена.
- Кнопки на карточке: **Открыть** (копирует пост и открывает группу), **Опубликовал** (группа уходит вниз списка и попадает в историю), **В блок** (группа больше не показывается, вернуть можно в «Истории»).
- Всё хранится только на телефоне. Своего сервера у приложения нет.

## Установка

Скачайте `gde-razmestit.apk` из релиза [apk](../../releases/tag/apk) и установите. Дальше приложение обновляется само: при запуске оно скачивает новую версию и включает её после перезапуска. Если новая версия не запустилась, приложение откатывается на прошлую.

## Как это собирается

При каждом пуше в `main` GitHub Actions (`.github/workflows/build.yml`):

1. собирает интерфейс из `web/` в `www/`;
2. упаковывает его в `bundle.zip` и пишет `update.json` с номером версии;
3. собирает APK (Capacitor) и выкладывает все три файла в релиз `apk`.

Переустанавливать APK нужно только при изменениях в `android/` или в нативных модулях.

## Структура

- `web/index.html`, `web/styles.css` — интерфейс
- `web/js/app.js` — экраны и логика
- `web/js/ai.js` — разбор поста и оценка групп (Claude API и простой режим)
- `web/js/sources.js` — поиск во ВКонтакте, Telegram (TGStat) и ссылки Facebook
- `web/js/store.js` — хранение на телефоне: настройки, история, блок-лист
- `web/js/native.js` — открытие ссылок в приложениях, буфер обмена, самообновление

Ключ подписи в `android/keystore/` общий и подходит только для личного использования.
Перед публикацией в Google Play замените его на приватный ключ, хранящийся вне репозитория.
